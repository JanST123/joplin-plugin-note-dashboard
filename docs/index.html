Features

Five sections, one panel.

Everything is computed from your notes. There's nothing to configure and no extra data to maintain. Click any entry to open its note.

⏰

Today

To-dos due up to today's 18:00 cutoff. Overdue ones come first with a red badge that shows how late they are.

📅

Next workday

To-dos due by the next workday's cutoff. The heading shows the weekday, and on Fridays that's Monday.

🗓

Later

Everything due further out, followed by to-dos with no due date, so open to-dos don't get lost.

🕘

Recently opened

Your last four opened notes. Joplin doesn't keep this history, so the plugin records it, and it survives restarts.

📌

Pinned

Put 📌 in a note's title to pin it. This works for plain notes and to-dos.

🔄

Always current

The panel refreshes when notes change, when a sync finishes, when an alarm fires and once a minute, so the cutoffs stay accurate.

Drag & drop

Reschedule by dragging.

Drag a row from the panel, or from Joplin's own note list, onto a section. You can drag several notes at once. Dropping a plain note on Today or Next workday also turns it into a to-do.

Drop on Today
today 16:00

Due this afternoon, with enough time left to get it done.

Drop on Next workday
next workday 08:00

Skips weekends: a Friday drop lands on Monday morning, not Saturday.

Drop on Later
no due date

Removes the date. The to-do stays listed under Later as undated.

In Joplin the due date is also the alarm time, so rescheduling a to-do moves its reminder too.

Why it works

Sections follow the calendar, not countdowns.

A rule like "Today = due within 8 hours" is a rolling window, and it breaks: at 07:00, something due today at 18:00 is 11 hours away and would show as tomorrow. Note Dashboard uses calendar days with an end-of-workday cutoff instead. Sections and drop times use the same model, so a to-do you drop on a section always appears in that section.

Today
Next workday (Fri → Mon)
Later
Fri now Fri 18:00 Mon 18:00 →

On a Friday, the middle section runs until Monday's cutoff, so items due over the weekend are included and a Friday drop (Monday 08:00) stays where you dropped it.

Install

Up and running in a minute.

Open the plugin settings

Go to Tools → Options → Plugins. On macOS it's Joplin → Settings → Plugins.

Search for “Note Dashboard” and click Install

Prefer a file? Download de.jan8.notedashboard.jpl from the npm package and use ⚙ → Install from file.

Restart Joplin

The panel appears in the sidebar. Use View → Toggle Note Dashboard to show or hide it.

Pin a note

Add 📌 to any note title and it shows up under Pinned.
